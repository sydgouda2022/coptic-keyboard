# Attribution, licences and redistribution

The repository provides an original headless Coptic input API and derived
lexicon datasets based on fixed editions of the KELLIA Comprehensive Coptic
Lexicon and Coptic SCRIPTORIUM orthographic inventory. Data derivation and
redistribution are governed by each underlying source's actual licence.
See `docs/SOURCES.md` for exact source revisions and integrity digests.

This repository does not assert an overall source-code licence and does not
assume that third-party lexica have an unrestricted licence. The npm package
is intentionally marked `private: true` until the owner completes the
separate code and data rights review. A published GitHub repository and a
documented public programming API do not by themselves grant reuse rights
to third parties. SHA-256 is an integrity checksum, not a publisher signature.
