# Coptic Keyboard + Lexicon

Independent, native Unicode Sahidic/Bohairic predictive keyboard and
the canonical, source-pinned Coptic lexicon master. Renpet consumes
versioned assets with checksum verification. The original open-source
text and Coptic dictionary supplements are retained as build inputs.

This package is independent of the Hieroglyphic Keyboard repository.
See SOURCE_PROVENANCE.json for the original source revision.
